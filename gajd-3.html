Claude Code: что это и что он делает за тебя

Для новичка3 минуты чтения

Чат с нейросетью выдаёт текст, а дальше всё копируешь, вставляешь и сохраняешь вручную. Claude Code берёт на себя и эту часть: создаёт файлы и папки, собирает страницы сайта, презентации, таблицы, проверяет результат и исправляет ошибки

Это как помощник с ключом от твоей рабочей папки: задачу объясняешь ему словами, а делает он сам. Ниже о том, что это за программа, что я в ней сделала, какие команды экономят больше всего времени и что нужно для старта

Главное за минуту

  1. Задачу ставишь словами, результат получаешь файлом
  2. Перед изменениями он спрашивает разрешение, читай окно
  3. Для больших задач сначала проси план

Что такое Claude Code

Claude это нейросеть американской компании Anthropic. Claude Code это её «рабочий» вариант: программа, которая ставится на компьютер и работает с твоими файлами

Слово «код» в названии пугает зря. Код, если он нужен, Claude Code пишет и проверяет сам, а задачу ты ставишь обычным русским языком

Чем он отличается от чата

В чате

Просишь текст, получаешь текст. Дальше вручную переносишь его в Word, на сайт, в презентацию

В Claude Code

Просишь результат, получаешь готовый файл в своей папке. Нужна презентация, будет файл презентации. Нужна страница сайта, будет страница, которая открывается в браузере

Ещё одно отличие: Claude Code помнит договорённости. Правила работы и всё важное о проекте хранятся в файлах, поэтому каждый новый разговор начинается не с нуля

Что я сделала с Claude Code

Я не программист, нейросетями занимаюсь параллельно с основной работой. За это время успела сделать:

  • карусели для Instagram и Telegram-канала
  • конспект обучающего курса в виде удобной веб-страницы
  • сайт-визитку
  • презентации для тренингов на основной работе
  • этот сайт с гайдами

Схема каждый раз одна: описываю словами, что хочу получить, смотрю, что вышло, и прошу поправить то, что не нравится

Как ставить ему задачу

Те же пять частей, что в чате: роль, задача, для кого, как выглядит результат, ограничения. Разница в том, что здесь результат сразу становится файлом, поэтому стоит сказать, куда его положить и как назвать

Гайд 1. Пять частей хорошего промта →

Промт

Сделай презентацию на 10 слайдов для новых сотрудников по теме [тема]. Крупный шрифт, спокойные цвета, на каждом слайде не больше 5 строк. Сохрани в папку «Презентации» под названием «Вводное занятие»

Перед тем как что-то изменить на компьютере, Claude Code спрашивает разрешение: появляется окно с кнопками. Прочитай, что он собирается сделать, и нажимай «Разрешить», только если понятно зачем

Команды и клавиши, которые экономят время

/init: памятка о проекте

Напиши /init, и Claude Code изучит папку и создаст файл CLAUDE.md с описанием проекта. Этот файл он перечитывает в начале каждого разговора. Допиши туда свои правила, например «отвечай только по-русски» или «в текстах без длинных тире», и повторять их больше не придётся

Shift+Tab: сначала план

Нажми Shift+Tab или выбери режим плана в переключателе под полем ввода, и Claude Code перейдёт в режим, где он только составляет план и ничего не меняет. Прочитай план, поправь словами, и только потом разреши делать. Для больших задач это спасает от переделок

Esc: стоп

Видишь, что он пошёл не туда, нажми Esc или кнопку остановки. Работа остановится, и можно объяснить заново

Картинка вместо объяснений

Скриншот можно вставить прямо в окно. «Вот как выглядит сейчас, сделай кнопку как на втором скриншоте» понятнее любого описания

/clear: чистый лист

Одна задача готова, берёшься за следующую? Набери /clear. Старая переписка не будет мешать новой

Что нужно для старта

  • Компьютер с Windows или Mac
  • Платная подписка Claude. Для начала хватает самого простого тарифа Pro
  • Бесплатная программа VS Code: в ней Claude Code удобнее всего, всё видно в одном окне

Официально Claude в России сейчас недоступен, поэтому пошаговую установку здесь не публикую. Вопросы про старт задавай в Telegram-канале

Кому это подходит

Тем, у кого много повторяющейся работы с файлами: презентации, таблицы, однотипные документы, страницы, посты. И тем, кто хочет свой сайт, бота или удобный рабочий инструмент, но не хочет нанимать программиста

Если нейросеть нужна пару раз в неделю, чтобы написать письмо или придумать пост, можно не спешить. Для этого хватит бесплатного чата из второго гайда
